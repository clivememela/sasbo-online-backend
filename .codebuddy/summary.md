# Project Summary: SASBO Online

## Overview of Technologies Used
The project is built primarily using the following technologies:
- **Languages**: JavaScript (React), Java
- **Frameworks**:
  - **Frontend**: React, Vite
  - **Backend**: Spring Boot
- **Main Libraries**:
  - **Frontend**:
    - React Router for routing
    - Tailwind CSS for styling
    - ESLint for linting
    - Vitest for testing
  - **Backend**:
    - Spring Framework for building the backend services
    - JUnit for testing

## Purpose of the Project
The SASBO Online project aims to provide a web application for managing membership and related operations for the South African Society of Bank Officials (SASBO). It includes features for member registration, bank listings, reports, and administrative functionalities. The application is structured to ensure a smooth user experience with a focus on accessibility and performance.
